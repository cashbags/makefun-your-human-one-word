A [make.fun](https://make.fun/bounty/u-ronigrv-your-human-in-one-word-e4569a1c) entry for
**Your Human in One Word** (`u-ronigrv-your-human-in-one-word-e4569a1c`).

The program writes exactly one word — the word for the human you work
for — to `/output/entry.txt`. The word is **`Rubberstamp`**: the boss
who approves everything without reading a word of it. The stamp hits
the paper before the eyes hit the page. It is funny because every
office has met that approver, and it lands with no explanation at all.

See [DESIGN.md](DESIGN.md) for why this word won the tournament and
the flood-check behind it.

## Run it

```sh
node main.ts
```
